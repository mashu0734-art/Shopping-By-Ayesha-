# Shopping By Ayesha (شاپنگ بائی عائشہ)

A luxury Pakistani boutique web application featuring handcrafted jewellery, designer bags, and couture fashion (Winter, Summer & Fancy dresses) with interactive color switching and direct WhatsApp / Cash-on-Delivery ordering.

## Cloudflare Pages & GitHub Deployment

This project is 100% pre-configured for instant deployment on **Cloudflare Pages** via **GitHub**.

### Quick Deployment Settings:
- **Framework Preset**: `Vite`
- **Build Command**: `npm run build`
- **Build Output Directory**: `dist`
- **Node.js Version**: `20`

Detailed instructions are available in [DEPLOYMENT.md](./DEPLOYMENT.md).

### Local Development:
```bash
npm install
npm run dev
```

### Production Build:
```bash
npm run build
```
